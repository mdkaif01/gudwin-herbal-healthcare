# GUDWIN Herbal Healthcare

Official website for **GUDWIN Herbal Healthcare**, a hair and scalp treatment clinic led by **Dr. Wali Ahad** in Mau, Uttar Pradesh.

This website is designed to provide patients with information about the clinic, available treatments, doctor profile, patient testimonials, hair transformation results, and an easy way to book a consultation online.

## Features

- Responsive modern design
- Hair treatment services
- Doctor profile
- Hair transformation gallery
- Patient testimonials
- FAQ section
- Google Maps integration
- WhatsApp support
- Consultation enquiry form
- Appointment booking modal
- SEO optimized
- Open Graph support
- Mobile friendly

## Technology

- React
- Vite
- Tailwind CSS
- FastAPI
- MongoDB
